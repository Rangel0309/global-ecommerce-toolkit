# Calculation reference

This document describes the formulas currently used in the toolkit.

## Contribution profit

```
profit = selling price - product cost - shipping - fees - taxes - ad cost
```

## Contribution margin

```
margin % = profit / selling price × 100
```

## Break-even CPA

```
break-even CPA = selling price - product cost - shipping - fees - taxes
```

This is the maximum acquisition cost before contribution profit reaches zero for the order assumptions entered.

## Break-even ROAS

```
break-even ROAS = selling price / break-even CPA
```

## Current ROAS

```
current ROAS = selling price / ad cost
```

## Important limitation

These formulas are intentionally simple and operate on a per-order basis. They do not automatically include refunds, chargebacks, customer support, warehousing, VAT treatment, income tax, recurring software, blended CAC, LTV or other business-specific costs unless the operator includes them in the inputs.
