# Contributing

Thanks for considering a contribution to Global Ecommerce Toolkit.

## Good first contributions

- Improve calculator formulas or test cases
- Add market research checklists
- Improve accessibility and responsive UI
- Add documentation and examples
- Report calculation edge cases

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Make your change.
4. Explain the reasoning in the pull request.
5. Include screenshots for UI changes when useful.

## Product principles

- Keep calculations transparent.
- Avoid unsupported claims about markets or profitability.
- Prefer user-editable assumptions over hard-coded "industry averages".
- Keep core functionality free and open source.

## Reporting bugs

Open an issue with:
- expected behavior
- actual behavior
- steps to reproduce
- browser/runtime information if relevant
